# sowmyaarajan.github.io

Personal portfolio of Sowmya Rajan, Senior Forward Deployed Engineer. Live at https://sowmyaarajan.github.io

A static site with no framework and no build step.

## Structure

```
index.html                 homepage
resume/                    web résumé and PDF
assets/css/styles.css      design tokens and components (dark and light themes)
assets/js/main.js          menu, scrollspy, theme toggle
assets/js/fieldwork.js     the investigation demo
assets/js/demos.js         "Try it" demos for the projects and tools (simulated, example data)
assets/js/hop.js           animated career line
assets/js/tour.js          the 60-second tour
assets/audio/              tour narration
```

## Preview locally

```
python -m http.server 8000
```

Then open http://localhost:8000.

## Editing rules

- Every claim must be supported by a public source.
- Customer names stay anonymised.
- No phone number anywhere in this repository.
- Demos are simulated in the browser with example data: no live services.
